# Now Playing redesign — warm "vinyl" look (mockup port)

## Context
Port the provided HTML mockup's look onto the Compose Now Playing screen. The mockup's element order (title/heart → quality pill → scrubber → transport → up next → file path → playlist pills → lyrics bar) **exactly matches the existing stack order**, so this is a restyle of existing composables — no re-layout, no data/ViewModel/DB changes. The ⋮ menu (button, `NowPlayingOptionsSheet`, pin editor, `menuActions`/pins logic) stays **untouched**.

Decisions confirmed with you: album-derived accent (not fixed coral) · light theme = mockup's warm cream, dark theme keeps its ambient with the new layout · re-add the collapse chevron.

## New shared styling: `ui/NpGlass.kt` (new file)
Mockup's glass pills. Plain translucency + hairline, **not** Haze — `LocalChromeHazeState` captures the scaffold's screens, not the player sheet's own content, so a real backdrop blur would frost the wrong layer (and the mockup blurs a soft gradient, which translucency already reproduces).
- `Modifier.npGlass(shape)`: light = white ~55–65% fill + white/70% 1dp border; dark = white ~7% fill + white/10% border; subtle shadow. Ink-aware via `npIsLight()`.
